# HNO Praxis Nord · teilbarer Website-Entwurf

Öffentliche Konferenz-Vorschau des Website-Vorschlags für die HNO Praxis Nord.
Die Praxisfotos und Inhalte wurden für diesen Entwurf aus dem privaten
Arbeits-Repository übernommen. Die Buchung im Widget ist eine reine
Browser-Demo: Anfragen werden nicht an eine Termin-API übertragen und
legen keine echten Termine an.

Die offizielle Praxiswebsite und bestehende Med.One-Seiten bleiben unverändert.
Der Entwurf ist mit `noindex,nofollow` gekennzeichnet.
